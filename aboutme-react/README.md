# About Me React Prototype

This folder contains a small Vite + React prototype for an About Me section. It
is separate from the deployed static portfolio in the project root.

## Purpose

The prototype explores reusable React components, Framer Motion animation, and
Tailwind utility classes using the same Sarah Collins portfolio content and
visual direction as the main static site.

## Run Locally

```bash
npm install
npm run dev
```

## Build Check

```bash
npm run build
```

## External Dependencies

Dependencies are listed in `package.json`. They are not custom learner code:

- React and React DOM for component rendering.
- Vite for development and production build tooling.
- Tailwind CSS, PostCSS, and Autoprefixer for utility styling.
- Framer Motion for animation.
- Lucide React for icons.

The root project remains the assessment-facing static portfolio.
