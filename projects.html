Selected work

Projects built around clear user goals

These examples show how I approach purpose, layout, accessibility, responsiveness, and testing. Each summary identifies whether the work is a live project or a developing interface concept.

Live project

Luma Hair Studio

A luxury salon website that helps prospective clients understand the brand, explore services, and move confidently towards an appointment.

User goal
Find services and reach the booking route quickly.
Design decision
A restrained black-and-white palette, generous spacing, and a prominent booking call to action support the premium brand.
Accessibility focus
Clear navigation labels, readable text, descriptive images, and keyboard-visible links.
Testing focus
Navigation, booking links, image scaling, mobile layout, and colour contrast.

Live project

The Ultimate Pub Quiz

An interactive quiz experience that lets players choose names and categories before beginning a round.

User goal
Set up a personalised quiz and understand how to begin.
Design decision
Grouped settings, large category choices, and visible status feedback make the setup sequence easier to scan.
Accessibility focus
High-contrast controls, readable labels, keyboard actions, and a visible sound control.
Testing focus
Form input, category selection, score behaviour, sound controls, responsive layout, and browser compatibility.

Interface concept

MindWeek Planning Dashboard

A calm planning dashboard concept for people who benefit from breaking a busy week into smaller, more manageable actions.

User goal
Choose one priority and reduce the effort needed to start.
Design decision
Soft colours, short prompts, grouped tools, and a visible "top three" area reduce visual and cognitive overload.
Accessibility focus
Plain language, large controls, labels that do not rely on icons alone, and generous spacing.
Next step
Test the dashboard with keyboard users and people who use planning tools for executive-function support.
